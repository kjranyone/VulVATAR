# VulVATAR ユーザーガイド & セットアップマニュアル

VulVATAR は、**Intel RealSense D435** デプスカメラを用いて演者の全身・上半身・表情をトラッキングし、Vulkan レンダリングした VRM アバターの映像を Windows 11 の仮想カメラ経由で配信ソフトへ送出するリアルタイムキャプチャアプリケーションです。

---

## 1. 動作環境 (システム要件)

本ソフトウェアを正常に動作させるには、以下の環境が必要です。

| 項目 | 必須要件 | 推奨環境 / 備考 |
|---|---|---|
| **OS** | **Windows 11 (64-bit, Version 21H2 / Build 22000 以降)** | Windows 11 の Media Foundation 仮想カメラ機能を使用するため、**Windows 10 以前では仮想カメラ機能が動作しません**。 |
| **キャプチャカメラ** | **Intel RealSense D435 / D435i** | **必須**（通常の Web カメラではトラッキングできません）。**USB 3.0 ポートに直結**してください（USB 2.0 接続時は帯域不足エラーとなります）。 |
| **GPU** | **DirectML / Vulkan 1.2+ 対応の独立 GPU** | NVIDIA GeForce RTX 2060 / AMD Radeon RX 5600 相当以上。<br>※RTMW3D-x ニューラルネットワーク推論を DirectML で高速実行します（CPU 推論時はフレームレートが低下します）。 |
| **メモリ** | 8 GB 以上 (16 GB 推奨) | アプリケーションおよび推論モデルの展開用。 |
| **音声デバイス** | マイク入力 | リップシンク（音声母音解析）用。 |

---

## 2. インストール手順

1. **インストーラの実行**
   - 配布された `VulVATAR-Setup-<バージョン>.exe` を実行します。
2. **管理者権限 (UAC) の承認**
   - 仮想カメラのシステム登録（COM / HKLM）およびサービス権限設定のため、**「ユーザー アカウント制御 (UAC)」ダイアログで「はい」をクリック**してください。
3. **インストール中のサービス再起動について**
   - インストーラは Windows のカメラ中継サービス (`Windows Camera Frame Server`) を一時停止・更新・再開します。
   - 他のカメラ使用アプリ（Chrome, Zoom, Teams, OBS 等）が開いている場合は、事前に閉じておくことを推奨します。
4. **完了**
   - デスクトップまたはスタートメニューのショートカットから「VulVATAR」を起動します。

## 3. カメラの設置と撮影環境の推奨条件

VulVATAR は、主に**「デスク配信スタイル（上半身・頭・腕が映り、手元がデスクにある状態）」**向けに精密な最適化が施されています。

### ① カメラの配置
- **設置位置**: モニターの上部、またはデスク正面。
- **距離**: 演者から **0.8 m 〜 1.2 m 程度**。
- **画角**: 顔・首・両肩・胸・肘が画面内に自然に収まるようにチルト角度を調整してください。

### ② 照明と赤外線（IR）環境
RealSense D435 は赤外線プロジェクターとステレオセンサーを用いて深度を測定します。
- **直射日光の回避**: 強い太陽光や直射日光が当たる部屋では、赤外線が白飛びして深度マップに穴（未計測領域）が開きます。カーテンを閉めて室内照明をご利用ください。
- **照明**: 演者の顔や上半身が影で真っ暗にならないよう、適度な明るさ（室内灯やリングライト等）を確保してください。

### ③ 服装の注意点
- **濃い黒色の服**: 赤外線を強く吸収する黒色素材の衣服を着ていると、カメラから胸や肩の深度が計測できなくなる場合があります。
- **極端にだぶついた服**: 腕や関節の輪郭が見えない衣装は、2D/3D キーポイント検出が不安定になる要因となります。

## 4. アバター (VRM / FBX) の準備と利用

### ① 対応フォーマット
- **VRM 1.0**: VulVATAR の標準アバターフォーマットです。VRoid Studio 等からエクスポートする際は「VRM 1.0」を推奨します。
- **VRM 0.x**: 従来の VRM 0.x もローダー shim によりベストエフォートで読み込みに対応しています。
- **FBX**: `.fbx` 形式の人型モデルの読み込みに対応しています。また、VRChat 向けモデル等の `.unitypackage` に含まれる二次小物理設定（`VRCPhysBone` / `VRCPhysBoneCollider`）の抽出・適用もサポートしています。

### ② アバターの読み込み
以下のいずれかの方法でアバター（`.vrm` / `.fbx`）を読み込めます:
- トップバーの **「アバターを開く」** ボタンをクリック、またはショートカット **`Ctrl+O`** を押してファイルを選択します。
- **「アバター」モード**（F1 キー）のライブラリパネルに登録されたアバター一覧からクリックして切り替えます。
- アバターフォルダ（`アバターフォルダを開く`）にファイルを配置すると、フォルダ監視により自動的にライブラリに反映されます。

## 5. 配信ソフト (OBS / Discord / Zoom / Meet) との連携

VulVATAR でレンダリングされたアバター映像は、Windows の仮想カメラ **`VulVATAR Virtual Camera`** としてシステム全体に公開されます。

### ① OBS Studio での利用
1. OBS の「ソース」追加（＋）から **「映像キャプチャデバイス」** を選択。
2. デバイス一覧から **「VulVATAR Virtual Camera」** を選択。
3. 解像度/FPSタイプを「既定値」または「1920x1080 / 60fps」に設定。
4. ※背景透過（アルファチャンネル）をご利用の場合は、VulVATAR の出力設定で「Alpha Mode」を有効にし、OBS 側でブレンドモードを調整してください。

### ② Web 会議（Zoom, Google Meet, Teams 等）での利用
1. 各アプリのカメラ設定を開きます。
2. カメラとして **「VulVATAR Virtual Camera」** を選択します。

## 6. トラブルシューティング (FAQ)

### Q. 「RealSense D435 が見つかりません (No RealSense D435 found)」と表示される
- **USB ポートの確認**: 必ず PC 本体の **青色または赤色の USB 3.0/3.1 ポート** に接続してください。USB 2.0 ポートや給電能力の低いハブ経由では認識されません。
- **ケーブルの確認**: RealSense 付属の USB 3.0 Type-C ケーブル、または定格を満たす Gen1/Gen2 ケーブルをご使用ください。
- **他のアプリとの競合**: Intel RealSense Viewer や他のアプリがカメラを開いていると占有され接続できません。他のアプリを完全に終了してください。

### Q. アバターが T ポーズのまま動かない / 固まる
- **トラッキング開始**: 画面左上の「カメラ開始 / トラッキング」ボタンが押されているか確認してください。
- **一時停止の解除**: **Space キー** を押すとトラッキングが一時停止（ポーズ）されます。もう一度 Space キーを押して再開してください。
- **カメラの視界**: カメラの前に演者がいない、または顔・肩が隠れているとトラッキングが待機状態になります。

### Q. 配信ソフトに「VulVATAR Virtual Camera」が表示されない / 映像が真っ暗
- **Windows 11 の確認**: 本機能は Windows 11 専用です。
- **カメラのプライバシー設定**: Windows の「設定」→「プライバシーとセキュリティ」→「カメラ」で、「デスクトップ アプリがカメラにアクセスできるようにする」がオンになっているか確認してください。
- **Frame Server サービスの再起動**:
  管理者権限の PowerShell で以下を実行してサービスを再起動してみてください。
  ```powershell
  sc.exe stop FrameServer
  sc.exe start FrameServer
  ```

### Q. 動作が重い・カクつく
- **DirectML 推論の確認**: ステータスバーに「`トラッキング: 稼働中 (DirectML)`」と表示されているか確認してください。もし `(CPU)` になっている場合、または「トラッキング設定」パネルで **「CPU のみで推論 (GPU を使わない)」** にチェックが入っている場合は、チェックを外して GPU 推論を有効にしてください。
- **解像度/FPS の調整**: カメラ設定で解像度を `1280x720` や `30 FPS` に下げることで負荷を軽減できます。
